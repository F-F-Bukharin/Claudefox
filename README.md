# Claudefox

Claudefox puts Claude in the Firefox sidebar. It reads and acts on your tabs, using your own Claude account through Claude Code on your PC.

Not affiliated with or endorsed by Anthropic or Mozilla.

## Install

Windows only, with Firefox 142 or newer. START HERE.txt lists what to install and walks through every step, starting with Set up Claudefox.bat.

## What's in here

- `extension/`: the Firefox add-on (the panel, the page tools and their safety checks).
- `host/`: the helper on your PC that links Firefox to Claude Code.
- `host/vendor/claude-video/`: the engine behind video watching, by Bradley Bonanno, under its own MIT license (see its LICENSE and NOTICE.md).
