Claudefox - setup for friends
=============================

A Claude panel in Firefox's sidebar that can read and act on your tabs, using YOUR Claude
subscription through Claude Code. Personal project, not made or endorsed by Anthropic or Mozilla.

Put this folder somewhere it can stay (for example Documents\Claudefox). If you move it
later, double-click "Set up Claudefox.bat" again.

You need
  - Windows 10 or 11, with Firefox.
  - Node.js (LTS): https://nodejs.org
  - Claude Code: https://code.claude.com/docs/en/setup
  - A Claude Pro or Max plan. Usage counts against your plan like any Claude Code use.

1. Run the setup
   Double-click "Set up Claudefox.bat". No admin needed. It does these in order:
     - installs the helper that links the add-on to Claude Code;
     - signs Claude Code in. A browser opens: check it is signed in to the claude.ai account
       you want the panel to use, then click Authorize. This is a separate profile, so it does
       not change Claude Code anywhere else on your PC;
     - copies the add-on's path and opens Firefox on the page for step 2.
   It is safe to run again. If a step stops with a message, fix that and run it again.

2. Load the add-on in Firefox
   Unsigned build (the usual one for now): Firefox opens about:debugging. Click
   "Load Temporary Add-on...", paste the path (Ctrl+V) and press Enter, or pick claudefox.xpi
   from this folder. Firefox forgets temporary add-ons when it closes, so load it again after
   each restart (the setup does not need to run again).
   Signed build (whoever sent this will say so; the folder then has a file called SIGNED):
   Firefox opens about:addons. Gear icon -> Install Add-on From File -> paste the path, Enter.
   It stays installed.
   Firefox Developer Edition and Nightly can keep an unsigned build too: about:config ->
   xpinstall.signatures.required = false, then install it from about:addons as above.

3. Open the panel
   The Claudefox toolbar button (or the puzzle-piece menu), or Alt+Shift+C. Sign in to
   claude.ai in a normal tab, then in the panel: Profile -> Sign in with Claude. Settings ->
   Connections should show the helper connected and Claude Code signed in.

Using it
  - Type normally to talk to Claude. Speed (Haiku) is quick and light on usage, Quality
    (Opus) is slower and better. Click the Speed / Quality button under the message box to
    switch. In Speed, the + on its left turns on Speed Plus.
  - Stop (top right) cuts everything off at once. Start brings it back.
  - Unsafe mode, file tools, watching videos, tools that run programs and plugin installs
    each ask first in a small Claudefox window outside Firefox. If you did not ask for it,
    press Cancel or Deny.
  - Army (Quality only): the octopus beside Quality opens a card with an On/Off switch. With
    it on, Opus leads up to five Haiku workers in background tabs for jobs that need many
    pages. A run uses much more of your plan than a normal reply: 5 a day is plenty.
  - Always on: Google sign-in pages are hands-off, Claude never types passwords, 2FA codes
    or payment details, and tools that give Claude a shell (like Desktop Commander) are never
    switched on.
  - Local pages (an HTML game, a saved page): Claude opens them only in folders you allow in
    the small Claudefox window. Firefox also needs this switch on, once: about:addons ->
    Claudefox -> Permissions and data -> Access local files on your computer.

Video watching (optional)
  Claude can watch a video: a web address, or a video file in a folder you allowed under
  Local folders (Profile, Permissions). It needs Python 3.10 or newer, yt-dlp and ffmpeg
  on this PC. Install them once:
    winget install Python.Python.3.12
    py -3 -m pip install -U yt-dlp
    winget install Gyan.FFmpeg
  Open a new window and check: py -3 --version, py -3 -m yt_dlp --version, ffmpeg -version.
  Then switch it on: Profile -> Permissions -> Watch videos, and press Yes in the small
  Claudefox window. Stop turns it off. The captions and frames Claude reads go to Claude
  like any page it reads.

Remove it
  about:addons -> remove Claudefox (a temporary one is gone when Firefox closes), then in
  PowerShell from this folder:
  powershell -ExecutionPolicy Bypass -File host\install.ps1 -Uninstall
