Claude in Zen: the output folder

When Settings > Saving files is set to "Store in output folder", the files Claude makes (charts, text, HTML, sheets and Word files) are kept here instead of being downloaded. Each file keeps its name. A name that is already taken gets " (2)", " (3)" and so on, so nothing is overwritten.

"Download now" is the default. It saves to Downloads\Claude in Zen, as before. If the helper is not running, or a file cannot be stored, the file is downloaded instead and the log says why.

This folder sits beside the mods folder. Git keeps only this README; the files themselves are not committed.
